## Project Talking Points

When asked "tell me about a project":
1. Start with the problem/goal
2. Explain your technical approach
3. Highlight specific technologies used
4. End with quantifiable impact

Example: "I built [project] to solve [problem]. I used [tech stack] to implement [solution]. This resulted in [metric improvement]."
