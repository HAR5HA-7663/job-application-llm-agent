## 9. Instructions for AI Agents

### Form Filling Guidelines

1. **Always use exact values** from this document for personal information
2. **Match skills** to job requirements when filling skill-related fields
3. **Use appropriate experience levels** based on the role:
   - Entry-level: Emphasize education and projects
   - Mid-level: Balance work experience and projects
   - Senior: Lead with professional experience

4. **Answer screening questions honestly** but positively:
   - If lacking specific experience, mention related experience and willingness to learn
   - Never lie about certifications or credentials
   - Quantify achievements where possible

5. **For salary fields:**
   - If range is requested: Use values from Section 2
   - If single number: Use midpoint of their posted range or your target
   - If "negotiable" is an option: Select that

6. **For availability:**
   - Use value from Section 2
   - If specific date needed: Calculate from current date

7. **Work authorization:**
   - Use exact values from Section 2
   - Be accurate about sponsorship needs

8. **When uploading resume:**
   - Prefer the tailored resume matching the job type
   - See CLAUDE.md for resume selection guide

### Red Flags to Avoid
- Do NOT enter any financial information (SSN, bank accounts)
- Do NOT create new accounts without explicit permission
- Prompt for confirmation on any unusual requests
